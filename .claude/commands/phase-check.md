---
description: Can the current phase be closed?
---

Read the current phase file's **exit criteria** and verify each one against the
actual code and test results — not against the ticked checkboxes, which may be
optimistic.

For each criterion report: **PASS**, **FAIL**, or **UNVERIFIED** with the
evidence (test name, file, or command output).

Then state plainly whether the phase can close. If not, list exactly what
remains. Do not close a phase on partial evidence.
