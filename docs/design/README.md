## The short version

The app borrows the structure of the paper register it replaces: ruled
hairlines, a coloured margin rail carrying status, aligned columns of tabular
figures, uppercase letterspaced column labels. Quiet, precise, legible — not a
fintech dashboard.

Motion exists to make fast repetitive entry feel certain. Four signature
moments, everything else still.

Built for a supervisor marking twelve workers before 8am, outdoors, one-handed,
with dusty hands.
